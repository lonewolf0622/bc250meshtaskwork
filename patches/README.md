# DirectMesh v1.0 patches

- `bc250-directmesh-mesa-26.2.1.patch`: the driver. Applies to stock Mesa 26.2.1 (`patch -p1 < ...` in the unpacked
  mesa-26.2.1 source).
- `bc250-directmesh-tests.patch`: optional offline test suites (`tests/bc250-mesh/`).
- `SHA256SUMS`: checksums (the release README is listed there too).

Build and usage: see the main [README](../README.md). The same files are attached to the
[DirectMesh v1.0 release](https://github.com/lonewolf0622/bc250meshtaskwork/releases/tag/directmesh-v1.0).
